# 📦 Controle de Estoque

Sistema web para gerenciamento simples de estoque com interface intuitiva.

## Recursos

✨ **Funcionalidades:**
- ➕ Adicionar produtos com nome, quantidade, preço e categoria
- ✏️ Editar produtos existentes
- 🗑️ Deletar produtos
- 📊 Visualizar relatório resumido com total de produtos, quantidade e valor
- 🔍 Buscar produtos por nome ou categoria
- 📥 Exportar dados em CSV
- 🚨 Alertas de estoque baixo ou em falta
- 💾 Dados salvos localmente (LocalStorage)

## Como Usar

1. Abra `index.html` em seu navegador
2. Adicione um novo produto preenchendo os campos
3. Gerenciace seus produtos com os botões de ação
4. Exporte seus dados em CSV quando necessário

## Tecnologias

- HTML5
- CSS3 (Gradientes e Animações)
- JavaScript (ES6+)
- LocalStorage para persistência

## Status de Produtos

- ✅ **OK** - Quantidade suficiente
- ⚠️ **Baixo** - Menos de 5 unidades
- ❌ **Em Falta** - Quantidade zerada
